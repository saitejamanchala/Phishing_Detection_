# 🛡️ Real-Time Phishing Website Detection System

An end-to-end Machine Learning web application designed to detect zero-day phishing URLs using structural and lexical feature extraction.

🚀 **Live Demo:** [Try the Phishing URL Detector](https://phishingdetection-44lh84pp6f8tanmsqvsu3l.streamlit.app/)

## 📌 Project Highlights
* **Accuracy:** 97.33% using a Random Forest Classifier.
* **Architecture:** Modular Python pipeline with ANOVA feature selection (`selected_features.pkl`).
* **Frontend:** Interactive Streamlit dashboard with real-time confidence scores and custom visual feedback cards.
* **Deployment:** Hosted on Streamlit Community Cloud.
